# kklab メモ帳

Python の [flet](https://flet.dev/) と SQLite3 で作成した、シンプルなメモ帳アプリです。
書き込みと消去に共通パスワードを設けています。

## 機能

- **書き込み** — 名前・メッセージ・パスワードを入力して書き込み。パスワードが一致しないと書き込めません（メッセージ未入力もブロック）。名前が空の場合は「名無しさん」になります。
- **消去** — 各メモの削除ボタンから確認ダイアログを開き、パスワードが一致した場合のみ削除します。
- **保存** — メモは SQLite3（`notes.db`）に保存され、書き込み時刻とともに新しい順で一覧表示されます。
- パスワードは初期値 **`kklab`** です。`main.py` 冒頭の `PASSWORD` 定数で変更できます。

> 補足: パスワードは書き込み・消去の「合言葉」として全員共通で使う簡易な仕組みです（メモごとの所有者認証ではありません）。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `main.py` | flet による UI（入力フォーム・メモ一覧・削除ダイアログ） |
| `db.py` | SQLite3 データ層（テーブル作成、メモの追加・取得・削除） |
| `pyproject.toml` / `uv.lock` | [uv](https://docs.astral.sh/uv/) による依存管理（flet 0.85.2） |
| `notes.db` | メモのデータ（初回起動時に自動生成。リポジトリには含めません） |

## 必要環境

- Python 3.11 以上
- [uv](https://docs.astral.sh/uv/)（パッケージ・仮想環境管理）

## セットアップ

```bash
git clone <このリポジトリ>
cd kklab-flet-board
uv sync          # 依存パッケージ（flet）を仮想環境にインストール
```

## 起動方法

### デスクトップアプリとして起動

```bash
uv run python main.py
```

### ブラウザで起動

```bash
uv run flet run --web main.py
```

`notes.db` は初回起動時に自動生成されます。

## 使い方

1. 上部のフォームに「名前」「メッセージ」「パスワード（`kklab`）」を入力し、**書き込む** を押すと保存されます。
2. メモを消すには、対象カードの🗑️ボタンを押し、ダイアログでパスワード（`kklab`）を入力して **削除** を押します。
